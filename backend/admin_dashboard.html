Recommendation rule CMS

Manage safe declarative rules used by the optional backend recommendation engine.

Rules are constrained to reviewed operators such as stress ≥ threshold, sleep < threshold, movement < threshold, mood ≤ threshold, energy ≤ threshold, sleep-quality ≤ threshold, or always. No arbitrary code or diagnosis logic can be entered here.
